SECÇÃO 5 - EVALUATION PIPELINE

Objetivo:
Treinar todos os modelos kNN em diferentes cenários, encontrar o melhor k para cada um,
e avaliar a performance final no conjunto de teste.

Fluxo de Execução:

1. FASE 1 - Seleção de k por Validação
   Função: SimpleEvaluation.evaluate_scenario()
   
   Para cada combinação (data_type, split_type, scenario):
   • Carrega dados do ficheiro .npz (train, val, test)
   • Testa múltiplos valores de k: [3, 5, 7]
   • Para cada k:
     - Treina modelo com KNNClassifier.fit(X_train, y_train)
     - Valida com KNNClassifier.score(X_val, y_val)
     - Regista accuracy de validação
   • Seleciona o k com melhor performance em validação
   • Guarda resultado: {best_k, val_acc, k_accuracies}

2. FASE 2 - Análise dos Melhores k
   Função: SimpleEvaluation.analyze_best_ks()
   
   Apresenta tabela com:
   • Data Type (features / embeddings)
   • Split Type (within / between)
   • Scenario (all / pca / relief)
   • Melhor k encontrado
   • Accuracy em validação
   
   Resultado: Visão geral do k optimal para cada cenário

3. FASE 3 - Retrain Final e Teste
   Função: SimpleEvaluation.retrain_and_test()
   Chama: SimpleEvaluation._retrain_and_test_single()
   
   Para cada cenário com o melhor k encontrado:
   • Combina train + val (80% dos dados totais)
   • Treina novo modelo: KNNClassifier.fit(X_trainval, y_trainval)
   • Avalia em teste: KNNClassifier.predict(X_test)
   • Calcula métricas:
     - Accuracy total
     - Matriz de confusão: confusion_matrix(y_test, y_pred_test)
     - Métricas por classe: precision, recall, F1-score
   • Guarda resultados em ficheiro JSON

Métodos Utilizados:

KNNClassifier (models/knn.py):
  • fit(X_train, y_train): Treina o modelo, guarda dados
  • score(X_test, y_test): Retorna accuracy (0.0 a 1.0)
  • predict(X_test): Retorna predições para cada amostra

confusion_matrix (models/knn.py):
  • Entrada: y_true (etiquetas verdadeiras), y_pred (predições)
  • Saída: matriz (n_classes x n_classes) com contagens

Estrutura de Dados:

Ficheiros de entrada (scenarios):
  data/processed/scenarios/{data_type}/{split_type}/{scenario}.npz
  • train_X, train_y (70% dos dados)
  • val_X, val_y (10% dos dados)
  • test_X, test_y (20% dos dados)

Combinações Testadas:
  • Data Types: features, embeddings
  • Split Types: within (mesmo participante), between (diferentes participantes)
  • Scenarios: all (todas as features), pca (90% variância), relief (top 15)
  • Valores de k: 3, 5, 7
  
  Total: 2 × 2 × 3 × 3 = 36 modelos testados

Saída:
  • Tabela de melhores k por scenario
  • Acuracies em teste para cada combinação
  • Matrizes de confusão
  • Métricas por classe (precision, recall, F1)
  • Ficheiro JSON com resultados completos
